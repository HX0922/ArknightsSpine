# ArknightsSpine

明日方舟（Arknights）Spine 2D 角色动画素材。

## 目录

- `Spine/` — Spine 素材：`char_*/ build_*/ token_*/` 等每个单位一个目录，含 `.skel`（骨架）、`.atlas`（图集）、PNG（纹理）与动画 JSON
- `Spine_frames/` — 各单位动画事件帧数据（JSON）
- `Spine/version` — 对应客户端 resVersion
